# Expenses tracker
Python CLI application for tracking expenses

## Set up
- Python 3.10+ required

git clone https://github.com/LazyAnTT/week-05-final.git
cd expense-tracker
python expense_tracker/app.py


## Apps CLI options
Programma darbojas interaktīvā režīmā ar izvēlni:

1) Add expenses
2) Show expenses
3) Filter by month
4) Group by categories
5) Delete transaction
6) Export CSV
7) Exit

For testing:
python -m unittest discover -s src/expense_tracker/tests
